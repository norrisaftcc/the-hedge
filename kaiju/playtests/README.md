# Playtests

Games played by people, kept as data. The balance bot (`tools/sim.mjs`) plays badly and greedily. These are the games that say how the monsters feel.

## Add a game

1. Play to the end. Press **Copy as text** under the review.
2. Make a file here named `NNN-monster-mission.md`, with the next free number: `002-radiosaur-coast.md`.
3. Use the template below. Paste the review as it was copied. Its last line names the build and the setup, so the game can be set up again.
4. Add what you tried and how it felt. A sentence is enough. Leave your name off if you like; never name anyone else.

One file per game, so two people adding games at once do not collide.

## Template

```
# NNN: monster, mission, result

- **Build:** the version, from the last line of the review (or "before 0.2.0" for older games)
- **Played:** date
- **By:** a name, or anonymous

## The review

(paste it here, as copied)

## Notes

What you tried. How it felt. What surprised you.

## Follow-up

Issues or findings this game led to. Leave empty; a maintainer fills it in.
```
